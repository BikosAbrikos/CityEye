# Build-промпт: CityEye (веб-сайт, MVP для хакатона)

> Скопируй всё ниже в кодинг-ИИ.

---

Ты — fullstack-разработчик. Построй MVP веб-приложения **CityEye** за ~1.5 дня. Команда — новички. Приоритет: рабочая демка, не идеальная архитектура. Детали, которые я не указал, выбирай разумно сам.

**Продукт.** CityEye (пилот — Алматы): житель фоткает проблему на улице (яма, мусор, фонарь, граффити, знак), ИИ распознаёт тип и серьёзность и ставит на карту. Главное — карта **«Индекс качества по районам»**, где районы подсвечены по баллу здоровья инфраструктуры.

**Чем отличаемся (не делай обычную форму жалоб):** интеллект поверх данных — AI-классификация по фото, дедупликация заявок через embeddings, агрегатный индекс районов. Герой продукта — карта, её строй и показывай первой.

**Стек:**
- Front: React (Vite) + Tailwind + Leaflet/OpenStreetMap
- Back: FastAPI + PostgreSQL + pgvector
- AI: GPT-4 Vision для распознавания (НЕ YOLO — нет времени на обучение); embeddings для дедупа

**Страницы:**
1. `/` — карта Алматы: районы-полигоны, залитые по индексу (зелёный/янтарный/красный) с баллом; поверх — пины проблем по серьёзности; панель с рейтингом районов и счётчиками. **Демо-ядро.**
2. `/report` — загрузка фото → Vision возвращает тип/серьёзность/описание → авто-карточка + геолокация → отправка. Показать блок «рядом N похожих — объединим».
3. `/admin` (если успеем) — список проблем по приоритету, отметить «решено».

**AI-логика:**
- Vision: промпт требует строго JSON `{type, severity, description}`, парсить безопасно.
- Дедуп: на новую заявку считаем embedding по `type+description`, ищем в pgvector открытые проблемы в радиусе ~80 м с cosine similarity > 0.85 и тем же типом → привязываем к существующей, иначе создаём новую.
- Индекс района: `100 − нормированная нагрузка от открытых проблем (low=1, medium=3, high=6)`, пересчёт при изменениях.

**Дизайн (графит + сигнальный янтарь, без «нейросетевого» вида):**
- Цвета: ink `#15181C`, фон `#F5F4F1`, карточки `#FFF`, акцент-янтарь `#F4A024`, индекс good `#3FA07E` / mid `#F4A024` / poor `#E1543B`.
- Шрифты: Archivo (заголовки), Inter (текст), JetBrains Mono (числа/координаты/проценты).
- Крупные скругления, мягкие тени, серьёзность и индекс — цветными бейджами.

**Порядок (соблюдать):** каркас + БД + seed-данные по Алматы → карта с индексом → форма с Vision → дедуп через embeddings → пересчёт индекса → (остаток времени) админка/деплой. Резать первым: админку и деплой. Не резать: карту и AI-распознавание.

Засей ~6 районов и ~25 проблем с реальными координатами Алматы, поставь рядом 2–3 заявки об одной яме — чтобы дедуп был виден вживую.
