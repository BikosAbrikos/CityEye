# 🏙️ CityEye — индекс качества городской среды

> Житель фоткает проблему на улице → ИИ распознаёт её → район получает балл здоровья на карте.
> Пилот — **Алматы**.

CityEye — это **не очередная форма жалоб**. Это карта здоровья города, которая
сама собирается из фотографий жителей.

---

## 💡 Чем мы отличаемся

| | Обычный сервис жалоб | **CityEye** |
|---|---|---|
| Ввод | Житель выбирает категорию вручную | 📸 **ИИ распознаёт** тип и серьёзность по фото |
| Дубликаты | 10 заявок про одну яму | 🔗 **Дедупликация** через AI-embeddings |
| Результат | Список тикетов | 🗺️ **Индекс качества по районам** на карте |

Три «умных» слоя поверх данных:
1. **AI-классификация фото** — GPT-4 Vision возвращает `{тип, серьёзность, описание}`.
2. **Дедупликация заявок** — embeddings + гео: новая заявка о той же яме рядом
   **объединяется** с существующей, а не плодит дубликаты.
3. **Агрегатный индекс района** — `100 − нагрузка от открытых проблем`, район
   подсвечивается 🟢 / 🟠 / 🔴.

---

## 🎬 Что показать жюри (60 секунд)

1. **Карта** (`/`) — районы Алматы залиты по индексу (зелёный → красный),
   поверх — пины проблем по серьёзности, справа рейтинг районов и счётчики.
2. **Сообщить** (`/report`) — загрузите фото → ИИ сам заполняет карточку →
   подтвердите точку на мини-карте → отправка.
3. **Дедупликация вживую** — отправьте заявку о **яме рядом с ул. Толе би**
   (≈ `43.2510, 76.9450`) → увидите **«рядом N похожих — объединим»**,
   новая точка НЕ создаётся, счётчик похожих растёт.
4. **Админка** (`/admin`) — проблемы по приоритету, кнопка «Решено» →
   индекс района сразу растёт.

## ▶️ Запуск за 2 минуты

**Backend** (Python 3.10):
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.seed                # засеять районы и проблемы Алматы
uvicorn app.main:app --reload     # → http://localhost:8000
```

**Frontend** (в другом окне):
```bash
cd frontend
npm install
npm run dev                       # → http://localhost:5173
```

Откройте **http://localhost:5173**. Готово.

> 🔑 С ключом `OPENAI_API_KEY` (в `backend/.env`) работает реальное распознавание фото.
> **Без ключа** приложение запускается в demo-режиме с правдоподобными ответами —
> ничего настраивать не нужно, демо не падает.
